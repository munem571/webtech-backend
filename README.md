# Book Quote & Passage Tracker (Backend)

Backend-Anwendung für das Modul **Webtechnologien** an der HTW Berlin.

## Projektbeschreibung
Diese Anwendung ermöglicht das Speichern, Verwalten und Abrufen von ausgewählten Buchpassagen, Zitaten und Seitenzahlen. In Milestone 1 wird die erste Spring-Boot-Backend-Schnittstelle bereitgestellt, die eine Liste von Beispiel-Passagen über eine REST-GET-Route zur Verfügung stellt.

## Tech-Stack
- **Java** mit Spring Boot (Spring Web)
- **Gradle**
